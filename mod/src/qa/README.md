# 客户端验收辅助源码

`src/qa/` 保留原项目的客户端与双客户端验收探针，独立于正式模组。运行 `scripts/gradle.ps1 qaJar` 可生成 `mod/build/qa/naiwa-qa.jar`，只用于隔离开发实例，不安装到普通游玩环境，也不进入正式发布包。

本仓库的标准自动检查是 `build runGameTestServer`：模型检查和 98 项服务端 GameTest。原工作区的整合包启动器、各光影实例、个人路径与自动安装脚本没有随仓库提交，因此 QA 探针源码的保留不代表仓库已具备一键复现全部历史双客户端画面矩阵的环境。

0.4.4 没有重新运行客户端画面、光影或公网联机实测。当前测试记录见[0.4.4 验证](../../../validation/0.4.4.md)，上传副本的独立构建检查见[上传准备记录](../../../validation/github-preparation.md)。修改渲染、视角或客户端同步后，仍应在隔离实例补做对应画面与双客户端验收。
