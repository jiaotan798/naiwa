# 奶蛙的模型源文件

0.5.0 的模型加入面部骨骼，大笑时嘴部和脸颊会跟着动。当前可编辑文件 [nailong_origin_zero.bbmodel](nailong_origin_zero.bbmodel) 包含 52 根骨骼、18,078 个顶点、36,001 个三角面、一张 2048×2048 贴图和 11 段动画。手指骨参与整蛊动作和道具定位。

[nailong_face_normals.json](nailong_face_normals.json) 保存鼻梁到嘴角修形所用的法线，需与当前源模型配套。由高模派生的低模包含 9,999 个三角面，用于远景。1.20.1 和 1.21.1 也用它绘制 Iris 实体阴影。 [模型与资源维护](../../docs/模型接入说明.md) · [素材指纹](../../third-party/asset-sha256.json)
