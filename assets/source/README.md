# 奶蛙的模型源文件

当前可编辑文件 [nailong_origin_zero.bbmodel](nailong_origin_zero.bbmodel) 包含 38 根骨骼、4,685 个顶点、9,207 个三角面、六张贴图和 11 段动画。模型基于此前的 38 骨模型修整脸颊、眼周和颈部曲面，手指骨参与整蛊动作和道具定位。

[nailong_face_normals.json](nailong_face_normals.json) 保存 1,526 个局部法线，需与当前源模型配套。由主网格派生的低模包含 2,222 个顶点、4,343 个三角面，用于远景。1.20.1 和 1.21.1 也用它绘制 Iris 实体阴影。 [模型与资源维护](../../docs/模型接入说明.md) · [素材指纹](../../third-party/asset-sha256.json)
