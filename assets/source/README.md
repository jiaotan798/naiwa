# 当前模型来源

0.4.5 使用用户提供的 用户提供的同步模型文件，工程固定入口仍为 `nailong_origin_zero.bbmodel`，字节完全一致；不修改下载目录原件。文件 8,029,093 字节，SHA256：`530ab823e6f66065e52b68d9d5a24b765640945cac8e6fca12a590098c7291b9`。

相对 0.4.4，3,580 个顶点、6,997 个三角面、38 根骨骼标识和顺序、网格顶点和面片索引及六张内嵌贴图字节保持一致；715 个顶点坐标、442 个面片数据及部分蒙皮权重变化。九段动画更新，`run` 和 `wave` 原样保留。不能将本次接入理解为只延长旧动画。

手指仍为从零计数的 36/37 号骨，整蛊姿势和道具定位归入对应手，腿骨仅为 26～35。飞升第一人称继续隐藏双手。31 个无面顶点保留索引与蒙皮，生成器仅为它们补单位法线。

全部 11 段由原生 Blockbench 以约 50 Hz 重新采样，原生姿态对照包含手指高权重点。`laugh` 为 8.25 秒，完整演出 9.65 秒，`ascend_hover` 为 3.04 秒；游戏飞升阶段时长仍由服务端独立控制。本体音轨取原素材 0.6～8.85 秒，原速播放，单段起拍约 1.44 秒、完整演出约 2.04 秒。


当前快照仅保留当前模型，不上传历史素材。重新采样入口见[模型接入说明](../../docs/模型接入说明.md)。
