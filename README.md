# 奶蛙

Minecraft Java 生存整蛊模组，模组 ID 为 `naiwa`，当前版本 **0.4.9**。奶蛙会在探索、采矿和日常劳作时突然现身，整蛊成功后捧腹大笑；玩家还能收集笑气、转化盾牌，并用奶蛙图腾体验变身飞升。

## 下载与安装

在 [Releases](https://github.com/jiaotan798/naiwa/releases) 下载所需版本的正式 JAR、`SHA256SUMS` 和安装说明，将 JAR 放入游戏实例的 `mods` 文件夹并替换旧版。每个实例只保留一个奶蛙版本，多人游戏的客户端与服务端均需安装同版。

| 项目 | 支持环境 |
| --- | --- |
| Minecraft | Java 版 1.21.1 |
| 加载器 | NeoForge 21.1.252 |
| Java | 21 |
| 动画前置 | 无需 YSM、GeckoLib 或其他动画模组 |

0.4.9 Release 的 JAR 对应上表的 1.21.1 NeoForge。仓库也提供 1.20.1 Forge／Fabric、1.21.1 Fabric、26.1.2 NeoForge／Fabric 的源码和[构建说明](ports/README.md)。普通游玩请安装对应游戏版本及加载器的成品 JAR，开发验收探针 `naiwa-qa.jar` 仅用于测试。

## 玩法

### 十种整蛊

| 场景 | 如何遇见与识破 |
| --- | --- |
| 玻璃镜像 | 面向五格内的普通玻璃窗口，奶蛙在另一侧模仿转头、蹲下、移动和起跳；持续看满八秒后大笑 |
| 门后变脸 | 打开木门后对侧现身；三秒不关门就大笑。及时关门后严肃等待三秒，期间重开就笑，否则离场 |
| 树干躲猫 | 砍原木时在树干对侧躲藏；正常砍掉遮挡原木后，它会扶空停顿，再开始大笑 |
| 矿洞摸鱼同事 | 在看不到天空的地下持镐挖矿，它在身后约五至六格装挖；真正挖掉方块并停镐后追加三声敲击，回头看见它后还会装挖约两秒，再藏镐转身大笑 |
| 钓鱼抢书 | 原版真正咬钩并有效收竿时，奶蛙可能截走本次渔获，拿着发光附魔书出水落岸后大笑；等待和空收竿不会提前出场 |
| 船尾偷渡 | 驾驶有空后座的普通木船时，奶蛙偷偷上船；松开方向键半秒后接手随机划船，回头持续看见后座半秒即可识破，重新按方向键立即恢复手动驾驶 |
| 苦力怕代班 | 原地停留约三秒后，在背后安全位置播放一次引燃声；及时回头对视便会露馅，不回头则挠头退场 |
| 假钻石钓人 | 用镐挖出真实钻石时，钻石可能变成会跑的诱饵；首次靠近后避让四秒、反复保持四格外，再露出奶蛙，大笑并消失后在原地原数交还本次钻石，保留时运结果 |
| 箱中探头 | 正常开箱并关闭界面后，奶蛙从箱内露头；停留至少两秒并被看到后大笑，箱子仍可正常存取 |
| 望远镜贴脸 | 真实开镜后显示镜内图片，同时在水平前方四格生成临时演员；放下撤图，看见演员半秒后大笑 |

首次观察到符合条件的玩家后至少等待十秒，一名玩家同时只安排一个场景。默认每次开始整蛊后进入五至十分钟随机间隔，同一种整蛊不连续安排；中止也不会跳过已开始的间隔。没有安全站位或路径时不强行出场，持原版盾期间优先处理盾牌转化。

镜像目前只支持普通完整玻璃；船尾偷渡不支持运输船、竹筏或其他模组载具。整蛊不会替玩家挖矿、补树、拆门或新建船只。钓鱼整蛊成功出场后，本次渔获不补发，附魔书只是演出道具；钻石整蛊则会在中止或重载时交还暂存的真实钻石。

详细触发、中止、掉落及多人规则见[完整玩法说明](docs/完整玩法说明.md)。

### 奶蛙盾

主手或副手拿着原版盾，在安全位置遇见奶蛙后，让它完整大笑，即可将选中的那面盾原位转化为奶蛙盾。演出中换手、收起或丢掉原盾会取消转化。

奶蛙盾保留原盾的耐久损耗、附魔、名称和适用物品数据，外观使用固定奶蛙纹章。每三次真正阻挡伤害蓄满一次进度，自动探头大笑，并向第三次格挡时记录的方向击退四格内、左右各 60° 的有效目标，水平力度1.8、地面抬升上限0.4，不附加伤害。空举盾不计数，同盟、自家宠物及玩家目标遵循过滤和服务器 PvP 规则。

未满进度跟随盾牌保存和转交，连续蓄满的释放按顺序播放。完整转化与击退规则见[盾牌玩法说明](docs/盾牌玩法说明.md)。

### 笑气瓶

主背包、快捷栏或副手带有空玻璃瓶时，奶蛙成功大笑期间会自动消耗一个空瓶，兑换一瓶笑气。同一只奶蛙每轮大笑最多交付一瓶；整蛊奖励优先归触发者，没有交付空间时不扣瓶。常驻奶蛙可空手右键逗笑，另有五分钟采集间隔。

右键投掷笑气瓶，破碎释放淡黄色烟雾与奶蛙表情，使破碎点三格内、无遮挡的普通怪物大笑 2.5 秒，暂时停止追击和攻击，受伤后提前结束。末影龙、凋灵和监守者免疫，玩家、动物和宠物不受控制；投掷破碎不返还空瓶。

随身携带也有副作用：每六十至一百八十秒随机漏气一次，玩家捧腹大笑 2.5 秒，仍可移动、举盾、进食和普通交互，但暂时不能主动攻击或使用武器。多瓶不加速，也不消耗瓶子；飞升期间暂停漏气。

### 奶蛙图腾与死亡嘲笑

十四种有序布局兼容材料摆放：**一个原版不死图腾 + 一瓶笑气瓶 → 一个奶蛙图腾**，返还一个空玻璃瓶。

主手或副手持有奶蛙图腾，成功抵挡致命伤害后消耗一个，获得保命效果并临时变成奶蛙。正常流程为半秒起手、两秒升高六格、悬停六秒、三秒缓降；顶部受阻时提前悬停，不会穿顶。期间可横向移动，触发者画面切到角色背后的第三人称，出现黑夜与金色圣光，结束后恢复原视角和真实天空。第一人称兼容路径隐藏双手和手持物，物品仍保留在槽位。

触发起提供三十秒生物攻击保护，飞升阶段始终保护；玩家与环境伤害仍按原规则处理。半空恢复人形后保留一次免摔保护，直到首次落地或入水。恢复人形并真正落到实体地面后，奶蛙才按当前位置和朝向在水平正前方三格出现大笑；受阻只尝试上下高度，入水结束飞升时继续等待上岸。

真实死亡则等待原版实际复活后，再在新位置的正前方出现嘲笑奶蛙。前方受阻时等待安全空间，不借用身边常驻奶蛙，也不把死亡地点或起飞地点当作出场点。

### 创造模式与命令

创造页「奶蛙」提供生成蛋、奶蛙盾、笑气瓶和奶蛙图腾；自然世界也有少量奶蛙生成。需要直接召唤时可使用：

```mcfunction
/summon naiwa:naiwa ~ ~ ~
```

管理员可检查指定动画，例如：

```mcfunction
/naiwa animation @e[type=naiwa:naiwa,limit=1,sort=nearest] ascend_hover
/naiwa animation @e[type=naiwa:naiwa,limit=1,sort=nearest] auto
```

`auto` 恢复正常活动。动画命令只控制模型，不会触发真实保命、玩家飞升或发放道具。

## 模组设置

进入单人存档后，打开「模组」列表，选择「奶蛙」→「配置」。联机以服务端配置为准，客户端本地改值不能改变服务器规则。

| 设置 | 默认值 | 可调范围与作用 |
| --- | --- | --- |
| 整蛊最小间隔 | 300 秒 | 0～86,400 秒；与最大值共同确定每次开始后的随机等待 |
| 整蛊最大间隔 | 600 秒 | 0～86,400 秒；两项相同为固定间隔，两项都为零则取消额外等待 |
| 允许同一种整蛊连续触发 | 关 | 开启后允许重复，不强制下一次重复 |

间隔调整用于下一次开始的整蛊，当前冷却不重置。复活与图腾落地嘲笑固定在正前方三格，旧配置校正时移除两个距离字段，保留其余三项。零间隔仍需满足场景条件，也不会同时启动多个整蛊。

默认配置文件为实例目录的 `config/naiwa-server.toml`，存档 `serverconfig/` 中的同名文件可覆盖默认值。字段、示例与旧配置迁移规则见[模组设置说明](docs/模组设置.md)。

## 构建与测试

安装 **JDK 21** 和 **Node.js 22 或更新版本**，设置 `JAVA_HOME` 并将 Java、Node 加入 `PATH`。首次构建需要联网下载 Gradle 和 NeoForge 依赖；仓库已保留 Gradle Wrapper、当前源模型和采样资源，普通构建无需 Blockbench 或 FFmpeg。

从完整仓库根目录运行：

```powershell
& .\scripts\gradle.ps1 build runGameTestServer
```

也可直接使用 Wrapper：

```powershell
& .\mod\gradlew.bat -p .\mod build runGameTestServer
```

Linux／macOS 对应命令为：

```bash
./mod/gradlew -p mod build runGameTestServer
```

成品输出到 `mod/build/libs/`。`build` 包含模型来源校验与断言检查，`runGameTestServer` 运行 108 项服务端游戏测试，测试目录不可用作实际游玩存档。客户端开发入口为同一工程的 `runClient`。

请保留仓库目录布局，`mod` 构建还会读取 `assets/runtime/` 和 `scripts/`。独立构建已在 Windows 验证，复用了依赖缓存；Linux／macOS 与空白缓存首次联网构建尚未验收。
