# 0.4.4 玻璃镜像修复验证

2026-10-25，Minecraft Java 1.21.1、NeoForge 21.1.252、Java 21。

原实现把玩家位置等距反射到玻璃另一侧，但奶蛙半宽 0.45 格，大于普通玩家半宽约 0.3 格。玩家能正常贴墙站立时，演员的反射位置可能与玻璃相交，逐 tick 安全检查随即取消演出。

出场与跟随现共用近墙位置规则：普通距离仍等距反射，近墙时与玻璃中心平面至少保持 0.951 格，沿墙位置和高度继续对应；实心障碍、路径碰撞及破坏玻璃仍正常中止。旧的两格演员距离门槛同时移除，改由实际安全检查验证近墙出场。

修复前两个朝向的近墙跟随回归均失败，校正过近的初始夹具后仍能复现；原有 94 项通过。修复后新增两朝向跟随、近墙直接触发与实心障碍中止四项回归，全部 98 项 GameTest 通过，最终 0.4.4 汇总耗时 11.87 秒。
