# 模型与资源维护

当前源文件为 [nailong_origin_zero.bbmodel](../assets/source/nailong_origin_zero.bbmodel)。`assets/runtime/` 里的资源使用一张贴图和全部 11 段动画，高模由 Blockbench 原生采样，低模从高模派生。游戏内会叠加整蛊程序姿势。 [模型与法线来源](../assets/source/README.md)

## 校验与采样

普通构建只校验已提交资源，不启动编辑器。可从仓库根目录单独运行：

```powershell
node .\scripts\bake-model.mjs --check
```

替换模型后，在 Windows 安装 Blockbench 5.2.1 并用 `BLOCKBENCH` 指定启动文件。Node.js 需支持内置 `fetch`、`WebSocket` 及 `import.meta.dirname`，本工程采用 Node.js 22 或更新版本：

```powershell
$env:BLOCKBENCH = 'C:\工具\Blockbench\Blockbench_5.2.1_portable.exe'
node .\scripts\bake-model.mjs
& .\scripts\gradle.ps1 build
```

采样脚本使用独立 `.bake-work/` 用户目录和本机回环调试端口，结束后关闭本次启动的编辑器。已有高模通过摘要校验时，可用 `node ./scripts/bake-model.mjs --lod-only` 直接重建低模。普通构建及单独重建低模无需启动 Blockbench。

## 维护约束

- 原生动画按 50 Hz 采样矩阵；游戏端插值与蒙皮，不能用简单欧拉角插值替代原编辑器曲线求值。
- `model-manifest.json` 记录源文件和产物 SHA256；`native-pose-checks.json` 提供 33 组独立姿态对照。两项检查文件不进入成品 JAR。
- 新增左右放松手指参与整蛊姿势和持书定位；本体、盾牌头部、箱中探头和图腾变身共用模型。
- 16 编辑单位为一格，源文件脚底为零。飞升六格由服务端玩法控制，不能烘焙进模型动画。
- 飞升第一人称隐藏双手及手持物；正式飞升保持背面第三人称。身体姿态及视角逻辑由现有渲染代码控制。

运行 `build` 会校验源文件摘要、蒙皮、贴图、手指归属、动画边界与原生姿态对照。服务端行为另执行 `runGameTestServer`，这些检查不能替代实际客户端画面验收。

## 盾牌资源

[盾牌源图](../assets/shield/naiwa-shield-v1.png)使用独立 UV，替换时需检查盾面、把手的取样矩形和透明边界。头部从实体网格的颈部以上裁切。后脑也受颈骨影响，只按头骨权重筛选会漏掉后脑。换模型时应复核切面、后脑及探头高度，头部和盾面正面均朝局部 +Z。

## 音效

完整大笑由 0.6 秒入场、8.25 秒大笑和 0.8 秒恢复组成。本体音轨 `laugh_full.ogg` 保留约 1.44 秒准备静音，动作与笑声在整段演出约 2.04 秒时起拍。盾牌音轨 `laugh_short.ogg` 在探头约 0.3 秒后播放，持续 1.7 秒。

普通构建无需 FFmpeg。把 FFmpeg 加入 `PATH` 后，运行 `node scripts/verify-laugh-sync.mjs` 可检查音轨时长、起拍和收尾。修改准备静音时应同时核对对应动画。 [素材来源](../THIRD_PARTY_NOTICES.md)

## 飞升特效

飞升画面分为起手、上升、悬停和缓降。金色光束随角色朝向旋转，地面光斑随玩家横移，高度取起飞时的脚底。雨丝从灰蓝向光轴附近的金色过渡，最后随圣光渐隐。阶段时长及碰顶、入水和落地规则见[奶蛙图腾](完整玩法说明.md#奶蛙图腾)。

1.21.1 NeoForge 的客户端渲染由 `NaiwaAscensionShapes` 提供几何和受光，`NaiwaAscensionVisuals` 在世界绘制后先画角色，再画透明特效。Iris 可能在着色器应用时更改画布和深度状态，`NaiwaWorldShader` 在该步骤之后重新绑定画布和设置深度写入。角色写入深度，透明圣光不写入，保留地形对飞升画面的遮挡。

`NaiwaAscensionBloom` 从独立的场景颜色副本提取暖色亮部，做双向模糊后合成。场景副本用于避免同时读写同一张纹理。窗口变化时同步缓冲尺寸，效果结束、换世界或着色器重载时释放自有缓冲。 [当前验证](../validation/0.5.0.md)
