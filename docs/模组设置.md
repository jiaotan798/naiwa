# 奶蛙模组设置

我把整蛊间隔和重复规则放在世界的服务端设置里。联机以服务器设置为准。下表适用于六个 Java 端口。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 整蛊最小间隔 | 300 秒 | 每次开始整蛊时，从最小值到最大值随机取一个间隔 |
| 整蛊最大间隔 | 600 秒 | 随机范围包含两端 |
| 允许同一种整蛊连续触发 | 关 | 开启后，下一轮可以出现上一轮的整蛊 |

秒数可填 0 到 86,400。两项都填 `60` 会固定等一分钟，都填 `0` 会取消额外等待。把大小填反时，按较小值和较大值取范围。新间隔从下一轮开始使用，已经排好的冷却会继续倒计时。设置只影响十种普通整蛊，盾牌转化、复活和图腾落地嘲讽各有自己的规则。

## NeoForge

进入自己的单人世界，在「模组 → 奶蛙 → 配置」里调整。专用服务器通常从实例目录的 `config/naiwa-server.toml` 读取。若世界目录下的 `serverconfig/` 有同名覆盖文件，以该世界生效的文件为准。

## Forge 1.20.1

启动一次世界后，关掉游戏或服务器，在该世界目录的 `serverconfig/naiwa-server.toml` 中修改。单人存档在 `saves/<存档名>/` 下，专服使用自己的世界目录。保存后重新进入世界或启动服务器。

NeoForge 和 Forge 的 TOML 使用以下字段和默认值。

```toml
prankIntervalMinSeconds = 300
prankIntervalMaxSeconds = 600
allowConsecutiveSamePrank = false
```

## Fabric

三个 Fabric 端都在世界启动时读取 `serverconfig/naiwa-server.json`。先开一次世界生成文件，再关掉游戏或服务器编辑。保存后重新进入世界或启动服务器。

```json
{
  "prankIntervalMinSeconds": 300,
  "prankIntervalMaxSeconds": 600,
  "allowConsecutiveSamePrank": false
}
```
