# 奶蛙模组设置

从 0.3.10 起，在单人存档中打开「模组」列表，选择「奶蛙」→「配置」，编辑整蛊服务端设置。进入存档后才能修改；主菜单未进入世界时及连接他人服务器时，该服务端配置入口可能为只读。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 整蛊最小间隔（秒） | 300 | 每次开始整蛊时，从最小至最大间隔中随机取值 |
| 整蛊最大间隔（秒） | 600 | 包含两端；两项相同就是固定间隔 |
| 允许同一种整蛊连续触发 | 关 | 开启后下一轮允许再次出现上一次的整蛊，但不强制重复 |
| 死亡复活出场距离（格） | 2.5 | 0.3.23 起，单独调整实际复活后奶蛙在当前水平正前方的优先出场距离 |
| 图腾落地出场距离（格） | 2.5 | 0.3.23 起，单独调整图腾飞升后真正落地时奶蛙在当前水平正前方的优先出场距离 |

秒数范围为 0～86,400。比如两项都填 `60` 是固定一分钟；两项都填 `0` 是没有额外间隔。最小值误填得比最大值大时，按两者较小/较大值作为有效范围，不会崩溃。

间隔和连续触发设置只影响十种普通整蛊。首次观察的十秒准备、复活/图腾嘲笑时序、普通盾牌现身及常驻本体采气间隔保持原规则。零间隔也不会让同一玩家同时演出多个场景，所有整蛊仍须满足原触发条件和安全检查。

**间隔修改用于下一次开始的整蛊，已经排定的当前冷却不重置。** 同种连续开关保存后按新值判断，但不能跳过尚未结束的冷却。开始后中止的整蛊仍计入上次类型和已开始的等待。

两个出场距离均支持 **1.5～16 格及小数**，分别生效。例如复活填 `6`、图腾填 `4.25`，就各自优先在六格和四点二五格处出场。受阻时沿正前方尝试增加一格或两格，任何候选均不得超过十六格；不改到侧后方，不回退到固定默认距离。默认仍为 2.5、3.5、4.5 格三个候选。

距离修改用于下一次出场尝试，包括尚在等待净空的待办；不移动已经现身或正在大笑的奶蛙。复活仍须原版实际重生，图腾仍须恢复人形且真正落地；两项距离不影响飞升高度、免摔、采气距离及等待/清理规则。

## 服务器及文件配置

联机时以服务端设置为准，NeoForge 会把实际配置同步给所有客户端；客户端本地改值不能改变服务器规则。在本项目使用的 NeoForge 21.1.252 中，默认文件为实例目录下的 `config/naiwa-server.toml`。首次启动后自动生成。

如果需要存档独立配置，可把同名文件放到该存档的 `serverconfig/` 中覆盖默认值：单人是 `saves/<存档>/serverconfig/naiwa-server.toml`，专用服是 `<世界目录>/serverconfig/naiwa-server.toml`。已有存档覆盖文件时，要修改实际生效的那份文件。服务器管理员可关服修改后再启动。

默认内容：

```toml
prankIntervalMinSeconds = 300
prankIntervalMaxSeconds = 600
allowConsecutiveSamePrank = false
respawnAppearDistance = 2.5
totemLandingAppearDistance = 2.5
```

固定十秒且允许同种连续，复活出场六格、图腾落地出场四点二五格：

```toml
prankIntervalMinSeconds = 10
prankIntervalMaxSeconds = 10
allowConsecutiveSamePrank = true
respawnAppearDistance = 6.0
totemLandingAppearDistance = 4.25
```

旧版配置在下次加载时自动补齐两个默认距离，保留已有间隔与连续触发值。未给出或不合法的字段由 NeoForge 配置校验修正，非有限值和越界距离不能通过校验；不改变玩家物品或存档中的整蛊历史。设置界面及联网行为采用 [NeoForge 原生配置系统](https://docs.neoforged.net/docs/1.21.1/misc/config/)。
