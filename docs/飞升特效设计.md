# 奶蛙图腾飞升特效

目标环境：Minecraft Java 1.21.1、NeoForge 21.1.252、Java 21。0.4.7 按用户提供的网易版 `naiwa-0.1.0.zip` 中的几何、材质和后处理公式实现。参考文件及摘要见[来源记录](../THIRD_PARTY_NOTICES.md)。

## 视觉结构

- 斜向圣光从角色面前 9 格、上方 8 格照入，向背后下方延伸，随身体朝向旋转。光源使用朝向摄像机的柔亮光片，主光片配合六张交叉光片形成宽阔光束，身体附近留出柔和空间。
- 起飞地面保留柔边金色光斑，随玩家横移；高度固定在首次看见起飞时的脚底，不随身体升高。
- 1920 条局部雨丝持续斜落，远处为灰蓝色，靠近圣光轴转为金色；24 枚闪烁光尘围绕起飞高度漂浮。
- 角色保留六张原贴图，以网易版正面受光、暗部底色和视角轮廓高光公式着色。身体先写深度，雨丝和光尘再进行遮挡测试。
- 本机画面提取暖色亮部，经过水平和垂直模糊，再以 0.55 倍泛光合成冷暗夜景。旁观者可见变身、角色受光和光尘，保持原世界天空与天气；主圣光、雨幕及屏幕泛光只影响触发者。
- 阶段提示沿用轻量原版紫水晶清响；中途进入追踪范围不补播起飞声。

## 演出时序

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 起手 | 0.5 秒 | 展臂入场，本机转为夜景，圣光与角色受光渐入 |
| 上升 | 2 秒 | 升高六格，斜向圣光与局部雨幕随角色移动 |
| 悬停 | 6 秒 | 保持展臂仰头姿势，雨丝连续下落，光尘持续闪烁 |
| 缓降 | 最长 3 秒 | 光照随角色下降，最后半秒特效渐隐 |

服务端玩法时序沿用现有规则：碰顶提前悬停，入水或结束后清理效果，变身横移、免摔保护、生物攻击保护和落地嘲笑不变。退出、死亡、换世界和离开追踪范围均清理对应客户端状态。

## 实现和维护

`NaiwaAscensionShapes` 负责参考几何与受光公式；`NaiwaModel.drawFlight` 复用原模型蒙皮，CPU 计算受光，以三倍颜色范围编码轮廓亮部。`NaiwaPlayerRenderer` 将主视图飞升角色推迟到世界绘制完成后，阴影及物品栏仍使用已有模型入口。

`NaiwaAscensionVisuals` 使用自有即时缓冲，在 `AFTER_LEVEL` 恢复事件世界矩阵后先绘角色、再绘透明特效。`NaiwaWorldShader.apply` 在原着色器应用完毕后绑定主画布并重设深度写入：角色开启，透明圣光关闭。Iris 会在着色器应用时更改画布及深度状态，因此不能只在 RenderType 的 setup 阶段设置。不得清空世界深度，否则会破坏地形遮挡。

`NaiwaAscensionBloom` 使用独立 `PostChain`：全尺寸场景副本 → 半尺寸亮部提取 → 四分之一尺寸双向模糊 → 全尺寸合成。初始场景副本避免纹理读写反馈，末尾仅拷颜色回主画布。窗口缩放同步尺寸；结束、登出、换世界和着色器重载释放自有 FBO 与顶点缓冲。

单个触发者最多输出 7812 个特效顶点（36 个圣光／地面光斑、7680 个雨丝、96 个光尘），另加原模型；每个旁观变身角色输出 96 个光尘顶点。此为几何数量，不代表已测得帧率或 GPU 耗时。没有新增运行依赖、网络协议、真实光源或世界天气修改。

本版实际验证见[0.4.7 记录](../validation/0.4.9.md)。Java 与网易渲染管线不同，按参考公式和构图复现，未进行网易客户端逐帧像素对比。
