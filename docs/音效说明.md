# 当前音效与校验

只保留游戏实际使用的OGG；原始参考媒体、视频和重新截取脚本不随源码。

- laugh_full.ogg：8.25秒本体音轨，保留约1.44秒准备静音；0.6秒入场后启动，完整演出约2.04秒音画起拍。
- laugh_short.ogg：1.7秒盾牌音轨，配合两秒探头演出。
- 完整大笑为0.6秒入场＋8.25秒大笑＋0.8秒恢复，共9.65秒。

普通构建无需FFmpeg。另装FFmpeg并加入PATH后，可运行 `node scripts/verify-laugh-sync.mjs` 检查现有OGG与源动画时长、起拍和收尾。重新制作声音需另行取得原素材，不能裁掉准备静音而不核对动作。来源与许可见[来源说明](../THIRD_PARTY_NOTICES.md)。
