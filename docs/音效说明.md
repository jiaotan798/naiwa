# 当前音效与校验

本源码快照只保留游戏实际使用的 OGG，不包含原始参考音频、参考视频或分镜，也不包含依赖原始媒体的重新截取脚本。作者已明确要求保留项目音效，不再作为本轮授权待确认项。

生产文件位于 `mod/src/main/resources/assets/naiwa/sounds/`：

- `laugh_full.ogg`：七秒本体音轨，保留约 2.04 秒准备静音，原速播放。完整演出的 0.6 秒入场后启动音轨，实际笑声约在 2.64 秒起拍。
- `laugh_short.ogg`：1.7 秒盾牌音轨，盾牌探头 0.3 秒后播放，与两秒演出配合。

当前模型 `laugh` 为 7.04 秒，新增 0.04 秒仅为无声表情收尾；完整入场、大笑与恢复共 8.44 秒。不能只删除声音的准备静音，否则会破坏已有音画同步。

普通构建不需要 FFmpeg。安装 FFmpeg 并加入 PATH 后，可从仓库根目录检查现有成品声音：

```powershell
node .\scripts\verify-laugh-sync.mjs
```

脚本读取当前源模型和正式 OGG，检查解码、时长及起拍；原始媒体不在本快照内，重新制作声音应从原开发项目进行。
