# 奶蛙盾牌玩法（0.4.3）

环境为 Minecraft Java 1.21.1、NeoForge 21.1.252、Java 21。当前使用 38 骨飞升精修模型、六张贴图与 11 段动画，来源及生成流程见[模型接入说明](模型接入说明.md)；盾面另用独立皮肤，不依赖 YSM 或额外动画模组。客户端与服务端安装同版 `naiwa-0.4.3.jar`。

## 相遇与转化

玩家主手或副手拿着原版盾，服务端首次观察到后至少等待三秒，按每秒一次的节奏寻找前方或身侧约 3.5 格的位置。只接受已经加载、有完整支撑、能容纳两格高身体、没有液体且视线无遮挡的位置；不能为表演拆方块、挤进玩家身体或强制加载区块。没有安全位置则五秒后重试。附近八格已有奶蛙时直接复用，成功现身后的再次自动现身间隔为五分钟。这些是当前实现的调试值；盾牌现身与十种整蛊的共享间隔独立，已有场景占用时不另行现身，持普通盾期间不启动新整蛊。

奶蛙靠近可见的持盾玩家后选中一只手的一面原版盾，先完整大笑 8.44 秒，服务端按 tick 在 8.45 秒完成转化。演出期间逐 tick 检查原盾是否仍在选中的手中；换手、收起、丢弃、转交、离开八格或被方块挡住均取消本轮转化。中途换回也不能恢复原轮，之后须重新完整演出。奶蛙死亡或命令替换动作同样取消转化。

演出结束时原位替换物品类型，使用原版 `transmuteCopy` 保留数量、耐久损耗、附魔、名称、旗帜染色、图案及其他适用组件，只将憋笑进度初始化为零。不会另发一面盾。双手都有普通盾时每轮只选一面；奶蛙盾不会反复转化。

创造页同时提供奶蛙盾和生成蛋。平原、向日葵平原、森林、桦木森林和沼泽加入权重 2、每组一只的低频生物生成，要求草方块支撑及亮度大于 8；实际出现仍受原版生物容量和生成规则影响。

## 格挡与击退

盾牌沿用原版五 tick 举盾延迟、336 耐久、木板修理、耐久损耗、附魔及破盾冷却。只有 NeoForge 实际伤害管线确认阻挡了正数伤害才累计一次；空举盾、绕盾、取消事件或没有阻挡的事件都不累计。同一个伤害上下文重复投递只能累计一次，不会误把同 tick 的不同攻击合并。

每面盾显示自己的 0/3、1/3、2/3 进度，第三次成功格挡立即消耗这三次进度并排队释放，短暂显示满条。下一次格挡立即开始新一轮。两轮都蓄满时按顺序演出，不因已有动画吞掉下一轮。

当前调试值为演出两秒，在开始后第 12 tick 击退一次。范围是持盾玩家当前脚部位置四格内、记录朝向左右各 60° 的目标。朝向在第三次格挡时记录，结算时重新检查距离、存活与方块视线，转头不会改打另一边。击退力度 0.9，遵从目标击退抗性，不附加伤害。

排除自己、旁观者、盔甲架、同盟及所有者接口能识别的自家生物，包括狼和坐骑。其他玩家遵从服务器 PvP 和队伍规则。范围、力度及是否进一步调整 PvP/宠物规则仍需生存体验校准。

每个玩家的已消耗释放顺序由服务端维护，仍由最初触发者结算；转交盾不会把已经排队的攻击转给接收者。未满进度跟随盾牌保存、换手或转交。退出、死亡、换维度、服务器停止清理临时释放，不清除未满进度。

## 表现与维护

奶蛙盾是独立物品 `naiwa:naiwa_shield`，采用原版像素材质风格的新贴图：金黄色盾缘、绿色铆钉、奶蛙纹章、奶白肚皮以及褐色木背和把手。普通盾 `minecraft:shield` 的贴图不受影响。旧存档中的奶蛙盾沿用原物品 ID，更新后直接使用新外观；耐久、名称、附魔和未满进度不迁移、不清空。

原盾底色和旗帜组件仍保留在物品数据中，显示使用固定奶蛙纹章，避免原图案覆盖独立皮肤；附魔闪光继续显示。常态为平面像素纹章，只有蓄满演出时才探出真正的三维头部。

盾牌头部从原网格的颈部以上选取，保留脸部及后脑，不生成独立可攻击实体。盾面正面与奶蛙头都朝向局部 +Z，所有视角使用同一方向。头部以头顶定位，演出时头顶最高为盾局部 0.55 格，低于盾顶 11/16 格，保留表情和头部转动。探头沿盾面向外伸出，不为第一人称可见而抬高或翻脸；持盾者被盾面遮挡是正常结果。

笑声已换为用户提供音轨的有效片段，保持原速：本体等待 0.6 秒入场后播放七秒，盾牌探头 0.3 秒后播放 1.7 秒，与两秒演出一起结束；单轮仅由服务端广播一次。本快照不含原件及视频分镜，正式音效参数见[音效说明](音效说明.md)。当前没有把视频中全部十八秒动作重新烘焙成动画。

关键入口为 `NaiwaEncounters`（安全现身）、`NaiwaEntity.conversion`（持有实例与原位转化）、`NaiwaShield`（真实格挡、去重、排队、击退和清理）。`naiwa:shield_charge` 是持久化整数组件；`naiwa:shield_laugh_start` 仅网络同步，不落盘，避免重进世界补播。客户端只读取组件显示，不发送格挡计数或击退指令。

`NaiwaMesh.headFaces()` 按三角面三个顶点的静态源坐标均满足 Y≥26 编辑单位筛出 1654 个三角面；后脑部分绑定颈骨，不能只按头骨权重筛选，否则会从后侧透见脸。替换模型时须一起检查颈部切面、完整后脑及盾上高度，不能为第一人称重新翻转朝向。模型采样资源仍只能通过脚本重建。

盾面美术由内置 imagegen 制作，原图在 [naiwa-shield-v1.png](../assets/shield/naiwa-shield-v1.png)；提示词不纳入本上传快照。生成结果为 1269×1240，UV 岛与原版不完全相同，因此 `NaiwaShieldSkin` 直接绑定自己的纹理，沿用原版盾面/把手尺寸并明确取样原图矩形。不会把该图混入方块图集或降低世界纹理的 mipmap。换图时要同步检查 UV 矩形和透明边界。

当前[完整玩法](完整玩法说明.md)已接入十种整蛊。普通盾转化仍优先于新整蛊，共享场景活动时不额外安排持盾现身；图腾击退复用同盟、宠物与 PvP 过滤，采用周围全方向范围。盾牌未满进度和旧物品 ID 保持兼容；模型资源以当前 38 骨版本为准。

0.4.3 飞升期间第一人称隐藏双手及手持物，包括奶蛙盾，结束后恢复；这不改变平时持盾的朝外探头规则。当前版本的回归及原版／Photon 双客户端覆盖见0.4.3 验证记录，不将飞升专项视作盾牌玩法全流程重新实测。
