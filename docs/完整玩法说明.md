# 奶蛙完整玩法

我给奶蛙做了十种生存整蛊。0.5.0 关闭了群系自然生成，奶蛙会在整蛊等玩法事件中出现。想直接见到它，可以使用创造模式里的生成蛋。奶蛙盾、笑气瓶和奶蛙图腾也能从创造物品页取得。

## 遇见奶蛙

默认每次开始整蛊后，下一次需等待五到十分钟，同一种整蛊不会连续出现。和平难度也能触发。手持原版盾时，奶蛙会优先尝试[盾牌转化](#奶蛙盾)。首次进入可观察范围后，还要给奶蛙至少十秒找出场机会。 [模组设置](模组设置.md)

| 整蛊 | 怎么触发 | 什么时候结束 |
| --- | --- | --- |
| 玻璃镜像 | 看向五格内的普通玻璃。另一侧有安全站位时，奶蛙会模仿你的移动、转头、蹲下和起跳。持续看满八秒，它就会大笑。贴着玻璃也能触发。 | 看向别处、离开窗口、绕到另一侧、打碎玻璃或挡住它的移动路线。 |
| 门后变脸 | 打开木门时，奶蛙会出现在门对面。门开满三秒，它就会笑。及时关门后，三秒内再打开也会逗笑它。 | 关门三秒后仍未重开，或拆门、受伤、走远。 |
| 树干躲猫 | 砍原木时，奶蛙会躲到树干另一边。砍掉挡住它的原木，它扶空后会停一下，再捧腹大笑。 | 把它赶走、离开或超时。 |
| 矿洞摸鱼同事 | 在看不到天空的地方持镐挖矿。奶蛙会在身后约五到六格的安全位置装作挖矿。挖掉方块并停手后，身后会多响三次敲击，间隔半秒。回头看它，它装挖约两秒，再藏镐转身大笑。 | 继续挥镐、移开视线会打断这段观察。离开、赶走奶蛙或超过三十秒时结束。 |
| 钓鱼抢书 | 鱼真正咬钩后收竿。如果水够深、奶蛙能安全跳到岸上，它会拿着一本发光附魔书跳出来，截走本次渔获。书是演出道具。 | 水浅、上不了岸或生成失败时，照常拿到渔获。奶蛙已经出水后，即使离开或打断演出，渔获也不会补发。 |
| 船尾偷渡 | 驾驶有空座的普通木船时，奶蛙会溜上后座。松开方向键半秒，它就会接手划船，每两到四秒换个方向。回头看见它半秒，它才会大笑。 | 再按方向键就能接回控制。下船或离水会停止接管，下船后在八格内仍可发现它。 |
| 苦力怕代班 | 原地朝同一方向停留约三秒，背后有安全站位时，奶蛙会模仿苦力怕的引燃声。回头对视半秒，它就会露馅。 | 三秒内没回头，它会挠头离开。走远、受伤或附近真有苦力怕引燃也会中止。 |
| 假钻石钓人 | 挖出实际掉落钻石的矿石时，钻石可能变成诱饵。第一次追到四格内，诱饵会继续躲四秒，之后才停下露馅。奶蛙消失后，会交还这次挖出的钻石，包括时运多出的部分。 | 无安全路线或用精准采集挖出矿石时，照常掉落。中途识破、离开或存档重载也会交还原钻石。 |
| 箱中探头 | 打开箱子后关掉界面。箱内有空间时，奶蛙会伸出头，箱盖看起来还开着。停留至少两秒并看见它，就会听到大笑。箱子仍可正常存取。 | 拆箱、赶走奶蛙、走远或超时。 |
| 望远镜贴脸 | 举起望远镜时，镜内会出现奶蛙的脸，正前方四格的安全地面也会出现一只奶蛙。放下望远镜后，继续看见它半秒，它就会大笑。 | 放下后转头、走出三格、换用其他物品或三十秒内没完成观察。 |

大笑结束后，整蛊中出现的奶蛙会退场。已经留在世界里的奶蛙也可以用空手逗笑。

## 奶蛙盾

主手或副手拿着原版盾，奶蛙会尝试在你前方或身侧约 3.5 格的安全位置现身。八格内已有奶蛙时，它也能过来。成功现身后，再次自动现身至少间隔五分钟。

奶蛙选中一面盾后，需要在你身边笑完约 9.65 秒。演出期间把盾换手、收起来、离开八格或被方块隔开，都会中断转化。笑完后，手里的盾会直接变成奶蛙盾，保留耐久、附魔、名称和旗帜数据，盾面显示奶蛙纹章。

每面盾单独累计三次有效格挡。第三次格挡后，盾上的奶蛙朝外探头大笑，击退四格内、格挡方向左右各 60° 的目标，水平击退力度为 1.8。队伍、宠物和服务器 PvP 规则同样适用。没攒满的进度随盾牌保存和转交，已触发的击退仍由原持盾者结算。 [盾牌资源与音效](模型接入说明.md#盾牌资源)

## 笑气瓶

奶蛙整蛊成功后，如果你的背包、快捷栏或副手有空玻璃瓶，大笑期间就会自动用一个空瓶换给你一瓶笑气。一轮大笑最多收一瓶。单个空瓶可以原位替换，成组的空瓶需要空位或可以合并的笑气瓶堆叠。常驻奶蛙会为三格内最近、无遮挡且带着空瓶的玩家兑换，间隔为五分钟。手动采集同样要求在三格内且视线无遮挡。

右键把笑气瓶扔出去。瓶子碎裂时冒出淡黄色烟雾和奶蛙表情，约五秒后消散。三格内、无遮挡的普通怪物会大笑 2.5 秒，暂时停止追击和攻击，受伤会提前结束。末影龙、凋灵和监守者免疫。投掷后不会返还空玻璃瓶。

带着笑气瓶时，每隔一到三分钟可能漏气一次，让你大笑 2.5 秒。大笑期间仍可移动、举盾和进食，近战和远程武器暂时用不了。携带多瓶不会加快漏气，也不会消耗瓶子。

## 奶蛙图腾

用一个原版不死图腾和一瓶笑气在工作台合成，配方支持十四种摆法，取走成品时返还一个空玻璃瓶。把奶蛙图腾放在主手或副手，受到可由图腾抵消的致命伤时，它会消耗一枚并保住你一命。

图腾生效后，玩家恢复到一点生命值，获得 60 秒生命恢复 II、30 秒伤害吸收 II 和 60 秒防火。角色变成奶蛙，镜头切到身后，在金色圣光下飞升。空中无遮挡时，先做半秒起手动作，再用两秒升高六格，悬停六秒，最后用最多三秒缓降。你可以横向移动，碰到头顶会提前悬停，落地或入水会提前结束演出。结束后恢复原视角。

生物攻击保护从触发时起持续约 30 秒。飞升结束后若仍在半空，第一次落地或入水前仍有这次落地保护。旁观者能看到变身、角色受光和光尘，圣光、雨幕和夜景只出现在触发者的画面上。 [飞升特效维护](模型接入说明.md#飞升特效)

恢复人形并落到实体地面后，奶蛙会到你正前方三格，大笑着嘲讽你。正前方没有安全站位时，会继续尝试最多十秒。飞升中落水会等你上岸。玩家真正死亡时，则等到重生后再按重生位置和朝向安排嘲讽。
