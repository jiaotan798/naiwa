# 奶蛙完整玩法 0.5.0

奶蛙有十种生存整蛊、奶蛙盾、笑气瓶、复活嘲讽与图腾飞升。0.5.0 中，奶蛙通过整蛊等玩法事件出现，也可使用生成蛋或命令召唤。联机时客户端和服务端安装对应加载器的同版 JAR。 [支持环境](../README.md#下载与安装)

0.4.7 按网易版参考包实现斜向宽圣光、局部灰蓝／金色雨幕、闪烁光尘、角色定向受光与暖色泛光夜景，保留轻量阶段提示音。旁观者可见变身角色受光与光尘；夜景、主圣光和雨幕只影响触发者。演出与维护约束见飞升特效设计，实际测试范围见[0.4.7 验证记录](../validation/0.4.9.md)。

0.4.8 同步网易版的门后三秒判断、假钻石四秒避让、盾牌水平力度 1.8、固定三格嘲笑及镜内图片；设置简化为三项，图腾使用十四种有序配方布局。实现与测试见[本版记录](../validation/0.4.9.md)。

0.4.9 将笑气瓶破碎表现接为 36 团淡黄色烟雾和 4 枚奶蛙表情，约五秒内长大、旋转并自然消散，碰到地形弱反弹，配合一次碎玻璃声。视觉寿命与怪物 2.5 秒控场分别计时；原玩法结算保持不变，见[本版记录](../validation/0.4.9.md)。

## 生存循环

0.4.4 修正玻璃镜像靠墙及沿墙移动时的取消：普通距离仍按固定平面等距镜像；玩家贴墙时，奶蛙因身体较宽，与玻璃中心平面至少保持 0.951 格距离，沿墙位置和高度继续跟随。该限制同时用于出场与跟随，贴近玻璃也可开始；其他实心方块阻挡位置或移动路径时仍会结束。

正常探索和劳作时遇见奶蛙，完成整蛊后，只要主背包、快捷栏或副手有空玻璃瓶，就会在奶蛙大笑期间自动兑换一瓶笑气，并显示消耗提示。无需把瓶子拿在手里或临时赶到奶蛙身边。笑气瓶可以投掷救急，也可以与原版不死图腾合成奶蛙图腾。持普通盾时仍可触发原有盾牌转化，详细规则见当前[盾牌玩法说明](盾牌玩法说明.md)。

创造物品页提供奶蛙生成蛋、奶蛙盾、笑气瓶和奶蛙图腾。原有动画命令仍只控制模型，不会额外触发保命或授予道具。

首次观察符合条件的玩家后至少等待十秒。一次只安排一个场景，默认开始后进入五至十分钟随机间隔，同一种默认不连续安排。0.3.10 可在[模组设置](模组设置.md)调整最小/最大间隔并允许同种连续；相同秒数表示固定间隔，两项均为零可取消额外等待。新间隔用于下一次开始，当前冷却保留；开关允许重复而不强制重复。没有合适场景不生成演员；忽略、中止和成功均不能跳过已开始的间隔。原版盾转化优先，持原版盾期间不启动新整蛊。

镜像首版只支持普通完整玻璃，不修改玻璃渲染和碰撞。光学观察允许透过选中平面的玻璃；0.4.0 的自动笑气奖励直接归本轮触发者，不要求绕过玻璃。保留的手动采集仍检查真实距离与遮挡。演员不挖矿、不补原木、不改木门、不创建新船。仅成功的钓鱼整蛊截走当次渔获，鱼竿耐久仍由原版结算一次。运输船、竹筏及其他模组载具不参加偷渡。

矿洞整蛊不限制洞穴群系、洞室大小或高度；大型地下空间同样适用，和平难度也可触发。原版六种镐均属于可用镐，其他模组的镐需加入原版 `minecraft:pickaxes` 物品标签。需要主副手都不持普通盾、共享间隔到期，并遵守同种连续设置。按玩家水平朝向在背后约 5～6 格找地面站位，优先正后方，受阻才找后侧，没有远处位置就跳过，不回退到贴身位置；挖脚下或高处不会把演员位置算进地面。实际挖掉方块并停止挥镐后约 0.5、1.0、1.5 秒各敲一下，共三次；只挥镐或挖掘被取消不算挖完。

奶蛙按可见碰撞面距离选择自己身边最近的方块，包括洞壁、地面或较低的顶面，不再朝着玩家原先挖掘的空处。玩家听声回头后，它仍面对这个方块装挖约两秒，再用约一秒藏镐并转向玩家，真正看向玩家后才开始大笑。玩家恢复挖掘或中途移开视线会重新计时；演出总时限仍为三十秒。头部俯仰复用原骨骼，未新增专门动画。整蛊不改变玩家正常采矿的掉落与耐久结算。

成功后播放 9.65 秒的完整大笑并清理临时演员。常驻奶蛙可被空手逗笑；死亡复活与图腾落地嘲笑均另建正前方临时演员，不挪用附近奶蛙，不改常驻本体的位置、物品或动作。两类嘲笑均固定在当前水平正前方三格，只尝试原高度、上方和下方，受阻不扩大水平距离。

会跑的钻石使用独立实体 `naiwa:diamond_decoy`，不继承物品掉落，演出中不能被玩家、漏斗或物品合并提前取走。本次真实钻石数量和组件保存在该实体中，追逐及大笑期间不生成可拾取钻石；先移除奶蛙，再在消失处交还原栈，不额外造钻石、不重抽时运，也不影响开采经验。提前中止、退出、死亡或换维度时同样交还；保存重载不继续追逐，而在暂存位置交还。路线优先沿玩家朝向，受矿壁阻挡时检查两侧及身后，每 0.2 格检查净空、支撑和危险方块；所有方向都不安全则保持正常掉落，不再因普通走动随机触发。

箱内只显示原模型头部，物理尺寸也缩小，不留全身隐形碰撞；不制作扶箱或翻倒动作。开盖仅为客户端视觉，不改变实际打开人数、红石、菜单或箱内物品，结束后恢复原版显示。望远镜只创建临时演员，不挪动常驻奶蛙、不改玩家倍率或转动镜头；共享间隔及同种连续设置仍然有效。客户端只申请固定四格演员，服务器独立验证使用状态、间隔、净空、视线及已加载区块；图片只对本轮触发者显示。旧版借用本体的存档仍保留恢复兼容。

本体动作包含入场和准备阶段。0.4.5 同步模型的 `laugh` 片段为 8.25 秒，完整演出 9.65 秒，身体在单段约 1.438 秒开始大笑。本体音轨从同一用户原素材取 0.6～8.85 秒，保持原速，保留约 1.44 秒准备静音；入场后启动，完整演出约 2.04 秒音画起拍。采气窗口随大笑片段边界结束，场景演员保留到恢复动作完整结束。

0.5.0 使用带面部骨骼的 52 骨模型，包含一张贴图和 11 段动画。整蛊姿势和持书定位使用左右手指骨。飞升悬停动画片段为 3.04 秒，实际游戏悬停六秒。 [模型接入说明](模型接入说明.md)

0.4.8 望远镜使用网易参考图片，按原图比例适配镜框内窗；实际演员固定四格，不改变玩家 FOV 或倍率。旧投影方案的历史实测保留在历史记录。

模型沿革：0.3.13 精修面部、0.3.15 换入 `bb-v08-round-cheeks` 圆脸模型，0.4.1 再换入飞升精修模型。旧模型的实际覆盖保留在圆脸模型记录，0.4.1 当时的模型接入及三轮音画见历史记录，本版见[0.4.5 记录](../validation/0.4.9.md)，不将旧模型记录视作当前模型全流程实测。

0.3.16 将矿洞停镐后的追加敲击增加为三次，在最后停镐后约 0.5、1.0、1.5 秒各响一次，音量参数从 0.6 提到 1.5。音源仍位于身后奶蛙处，保留空间方向和距离衰减，不改变玩家的全局音量设置。实测范围见矿洞敲击记录。

0.3.18 将假钻石整蛊改为接管本次挖矿的真实钻石，奶蛙大笑并消失后才原数交还；取消、卸载及重载也保留结算。持续挥镐不再被当成停留观察而触发苦力怕代班抢占。规则与覆盖范围见钻石整蛊记录。

等待和咬钩期间没有水下演员、预先露出的绿眼睛或额外水花提示。0.3.7 在原版有效收竿的所有事件监听结束后、实际掉落之前，验证两格深起跳空间和完整可达出水弧线；演员成功加入世界后才截走当次全部渔获并开始冷却。复用原版取消结算分支收回浮漂、扣一次耐久，不发本次渔获、经验或钓鱼成就。未触发整蛊时完全沿用原版收竿结算。

附魔书是固定演出道具，不代表原版此次真的抽到了书；出水到捧腹大笑都拿在手里，位置跟随实际右手掌。道具不含可领取的附魔，附魔光效由组件固定开启；概率为零的装备掉落禁止击杀取书，退场、退出和区块重载也不留下书。开始演出后打断不会退还被抢走的渔获。

岸点搜索覆盖 2.5、3.5、4.5 格近邻圈及侧后方，考虑浮漂或船脚部略低于整数水面时的高度差，最高检查中心取整后三格、最低两格。收竿时先验证完整出水弧线，不改河床或树叶；水下身体空间不足或所有出水路线受阻时不生成演员、不截走渔获。

船尾偷渡的奶蛙留在真实后座。停手按玩家的原始方向输入判断，不按船速判断，因此惯性和奶蛙接管后的移动不会打断接管。随机航行通过原版划船输入实现，保留原版浮力、碰撞和联机同步；玩家任何方向键均优先，不强制转动玩家镜头。本轮允许玩家自行回头看正后座，大笑期间保持这一转头范围，退场后恢复原版限制。玩家看向奶蛙之前不播放憋笑、短笑或大笑，也不再要求先靠岸下船；下船后八格内仍可观察露馅，但不再自动划船。

## 笑气瓶

入场结束后至收场之前自动检查空瓶。成功整蛊、复活嘲笑和图腾落地嘲笑的奖励归本轮触发者，不要求把瓶子选中或赶到三格内；更近的旁观者不会自动抢走。场景中止、退出或换维度不事后补发。盾牌转化大笑优先为持盾触发者兑换；普通常驻奶蛙没有所属场景时，只为三格内无遮挡、持有空瓶的最近玩家自动收集。

同一只奶蛙一轮大笑最多交付一瓶，自动与原手动入口共用这一限制。消耗一个玻璃瓶换取一个笑气瓶，不扫描箱子或潜影盒。优先把来源格的单个空瓶原位替换；整组空瓶需要空格或可合并的笑气堆叠，包括副手。完全没有交付空间时不扣瓶、不占用本轮次数；当前大笑结束前腾格或补入空瓶仍可自动重试。成功后显示“自动收集到 1 瓶笑气，已消耗 1 个玻璃瓶”。

保留的手动采集距离为三格且需无遮挡。常驻本体另有五分钟采集间隔，重播大笑或保存重载不会重置，避免连续逗笑刷瓶。大笑本身的动画、音轨和结束时刻保持原样，不另加留场等待。

右键投掷，服务端成功创建投掷物后才消耗一瓶；破碎不返空瓶。破碎点三格内、无遮挡的普通怪物大笑 2.5 秒，暂停 AI 追击和攻击，实际受伤后提前结束。末影龙、凋灵和监守者首版免疫，名单在 `data/naiwa/tags/entity_type/gas_immune.json`；不控制玩家、动物和宠物。

主背包、快捷栏和副手携带时，每六十至一百八十秒随机漏气一次，多瓶不加速、不消耗。玩家捧腹大笑 2.5 秒，保留移动、举盾、进食和普通交互，暂停近战及弓弩、三叉戟等武器使用；已离手的投掷物正常结算。移除最后一瓶取消尚未触发的计时，已开始的大笑仍正常结束。死亡、退出和换维度清理计时与临时动作。飞升期间暂停漏气，结束后重新抽取间隔。

## 奶蛙图腾

十四种有序布局覆盖材料摆放：一个原版不死图腾 + 一瓶笑气瓶 → 一个奶蛙图腾，返还一个空玻璃瓶。配方使用原版工作台消耗及余料机制，预览、取消和批量合成不另行派发物品。

主手或副手持有时进入真实保命检查，沿用原版手顺序和无法被图腾防御的伤害规则，也尊重取消图腾使用的事件。成功后消耗一个，恢复到一生命值，获得六十秒生命恢复 II、三十秒伤害吸收 II 及六十秒防火。一次广播图腾演出与周围击退；附近同盟、宠物、服务器 PvP 限制沿用奶蛙盾过滤。保命不进入真实死亡流程。

随后玩家保持身份、背包和装备，临时显示为奶蛙；自动切到角色背后的第三人称，期间保持背面视角，结束、死亡、退出或玩家实例变化后恢复触发前视角。触发后本机天空立即按黑夜显示，一道上窄下宽、连续渐隐的金色圣光从天空照向玩家，随玩家水平移动；玩家在光锥内部飞升并保持明亮可见。效果只影响触发者画面，结束、死亡或退出后恢复当前真实天空、雾色和光照，不修改世界时间、天气或方块。画面效果随飞升结束关闭，不等待三十秒攻击保护到期。普通无遮挡流程约十一点五秒：

1. 半秒展臂仰头起手。
2. 两秒内按缓出曲线升高六格，以触发时脚部高度为基准。半空触发清除原下坠速度。
3. 悬停六秒，轻微浮动只影响模型，不抬高实际位置。
4. 三秒内以每秒两格缓降；提前落地或入水立即结束，超时恢复人形并正常下落。

飞升期间第一人称隐藏双手和手持物，物品保留在槽位；效果结束后恢复正常显示，HUD 和图腾激活动画保留。

触发起提供三十秒生物攻击保护，飞升阶段始终保护：清除附近生物对本玩家的追击目标及攻击记忆，阻止重新选中，并拦截生物来源的近战、箭矢、魔法与爆炸伤害。正常落地后保留剩余保护时间；死亡、退出、换维度或主动清理取消，三十秒到期恢复正常。玩家与环境伤害仍沿用原规则，本次落地免摔独立保留。

碰顶时只走实际碰撞允许的距离，立即进入悬停，不穿顶或在障碍移除后补升。起飞、悬停和缓降期间允许正常横向移动，不再额外减速，圣光跟随水平位置；高度仍由服务端控制，不能通过按键再次爬升。高度同步保留原版水平移动和碰撞，不使用每 tick 普通传送锁住方向输入。飞升阶段可使用原有物品与攻击，笑气捧腹不会覆盖变身姿态。

飞升起手、上升、悬停和半空恢复人形时不生成嘲笑奶蛙。玩家恢复人形并实际落到实体地面后，才按当前落点和水平朝向，在水平正前方三格选择安全高度出现临时奶蛙，面向玩家播放一次完整大笑。不沿用触发位置、不转向侧后方，也不挪用身边常驻奶蛙。前方受阻时从首次落地起最多重试十秒；没有安全空间则取消，不穿墙生成。

入水或坐在载具中不算落到实体地面；飞升入水结束后继续等上岸。退出、换维度、死亡或主动清理会取消本次落地待办。等待期间不启动另一种整蛊抢位，也不会延长一次免摔资格。

一次落地免摔保护独立于模型计时：深坑中恢复人形后仍保留，到首次落地或入水消耗。其他伤害不被这条保护取消。换维度、退出或中断恢复原重力与速度修正；崩溃后登录也恢复原重力。真实死亡不把本次免摔资格交给重生玩家。

正常情况下本次飞升落地不会摔死；如果后续独立摔落、其他伤害或模组影响仍造成真实死亡，立即取消落地嘲笑及已开始的临时演出，只保留复活点的死亡嘲笑，不把旧图腾演出带给重生玩家。

真实死亡时只记录一次待复活嘲笑，在原版完成实际重生后，按新玩家实例的当前位置和水平朝向，在水平正前方三格选择安全高度出现临时奶蛙，面向玩家播放完整大笑。死亡位置、旧床坐标及朝向均不作为出场依据，不借用常驻奶蛙，也不向侧后方兜底。前方受阻时保留待办并暂停其他整蛊，后续按玩家当前朝向重试；玩家转向后可在新的正前方出场。只有成功生成才消费这次待办，退出和清理旧场景不会误删，持续站立不会重复出场。

## 维护入口

- `NaiwaPranks`：共享调度、固定镜面、十种场景、真实死亡待办和演员清理。
- `NaiwaDecoy` / `client/NaiwaDecoyRenderer`：可被戳穿的独立诱饵和原版钻石外观；不复用可进入物品结算的 `ItemEntity`。
- `FishingHookMixin` / `NaiwaPranks.stealFishingCatch`：有效收竿的最终取消检查处原子抢书；NeoForge 的 `getDrops()` 是副本，不能靠清空它拦截掉落。升级游戏或与修改同一结算点的模组组合时须重测。
- `NaiwaEntity.collectAutomatically` / `collectSlot`：从主背包、快捷栏、副手自动选瓶，与手动入口共用服务端原子兑换、单轮次数和持久化冷却。原版背包空间接口同时检查副手可合并堆叠。
- `NaiwaPranks.Scene.tick`：成功大笑期间只为所属玩家尝试自动兑换；不放宽场景有效性，也不在失败清理时补发。
- `LaughGasItem` / `LaughGasProjectile`：成功投掷后扣物品，首次碰撞结算一次范围效果并广播两组自定义粒子；`client/NaiwaGasParticles` 按网易参数实现五秒烟雾、表情、碰撞及回收，使用原版透明粒子通道。
- `NaiwaGameplay`：漏气、控场、真实保命和四阶段飞升；`MobMixin` 只暂停 AI，不修改存档 `NoAI`。
- `NaiwaFlightHeight` / `FlightNetworkMixin`：只同步服务端高度，保留横移；仅在服务器授予的飞升效果期间豁免悬空踢出，不开启全服飞行权限。
- `client/NaiwaAscensionVisuals` / `IrisWorldTimeMixin`：连续渐隐的金色圣光与小光尘；可选覆盖 Iris 绘制时钟，世界真实时间仍保持不变。圣光使用独立着色器，在最终世界阶段向主画布输出并还原矩阵，避免被光影内部缓冲覆盖或被发光实体规则截出硬边。光影兼容范围以本版实际记录为准。
- `client/NaiwaAscensionShapes`：斜向圣光、地面光斑、1920 条局部雨丝及 24 枚光尘；使用连续客户端渲染时钟，地面与光尘以首次追踪到的起飞高度为基准。
- `NaiwaEffectSync` / `LivingEntityMixin`：两种视觉效果实际变更后向追踪者同步，首次追踪补发当前剩余时间，支持旁观者与重新进入视野。
- `NaiwaPlayerRenderer.hand`：飞升期间只取消主副手绘制，不提交奶蛙手或手持物网格；结束后交回原版。正式飞升仍固定背面视角，第一人称由独立探针覆盖兼容路径。
- `client/` 与客户端 mixin：人形捧腹、非人形抖动和临时玩家模型。
- `scripts/make-icons.mjs`：四张小型像素图标的固定源稿；`bake-model.mjs` 继续负责原模型资源，不手改采样产物。
- `shaders/core/holy_light.*` 控制程序光片及雨丝；`flight_body.*` 与 `NaiwaModel.drawFlight` 控制角色受光；`NaiwaAscensionBloom` 负责暖色提取、双向模糊和夜景合成。`NaiwaWorldShader` 在着色器应用后重新绑定主画布并明确深度写入，保持角色自遮挡及世界深度测试；不生成真实光源或改方块亮度。

核心数值为首版调试值，仍需真实生存平衡体验。动作使用原模型采样与程序姿势层；程序层依赖现有骨号及切面，换模型须同步检查。构建、测试及实机范围以本版验证记录为准，不把截图探针当成自然场景全覆盖。
